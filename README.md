# TrafficGuard Pro

A starter Android app inspired by the concept of a privacy/security traffic monitor, with premium subscription gating and ad placement hooks.

This repository contains an MVP UI and architecture skeleton to continue developing features like:

- live traffic monitoring dashboard
- app-by-app network usage
- premium upgrade flow
- ad banner / interstitial placeholders
- firewall and privacy controls

## Stack

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK 34

## Project structure

- `app/` — Android application source code
- `build.gradle.kts` — root Gradle configuration
- `settings.gradle.kts` — project settings
- `gradle.properties` — Gradle properties

## Notes

This is a clean starter build intended for rapid iteration. It is not a direct clone of any existing product, and all branding and assets are original.

## Run locally

Open the project in Android Studio and sync Gradle.
